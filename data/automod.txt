DISCORD AUTOMOD — keep commands in one channel
==========================================================

Server Settings -> AutoMod -> Create your own
  Trigger:  Custom Keywords
  Action:   Block Message  (and Send Alert if you want a log)
  Exempt:   your bot channel, under 'Allow specific channels'

Anyone with Administrator bypasses AutoMod, so test it on an
account that is not you.

OPTION 2 — one regex (never goes stale)
----------------------------------------------------------
Paste into 'Regex Patterns'. One line, and it covers every
command including ones added later:

(?i)(?:^|\s)\$[a-z]{1,24}\b

It blocks anything shaped like $word, which means it also
stops people typing a command while explaining one. In a
channel where commands are banned that is usually the point.

Listing every command as its own pattern would take 24 patterns and Discord allows 10, which is why this is a catch-all rather
than an exact list.
