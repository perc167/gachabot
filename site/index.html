Getting it working on your server

Six steps, in order. The first two matter most — everything after them is taste.

01

Add the bot

Run $invite in a server that already has it, or use the button at the top of this page. It asks for permission to send messages, embed links and attach files — nothing else.

02

Give it one channel

Left alone the bot answers everywhere, which gets old fast in a busy server.

$channelallow #bot-chat

$channellist shows which channels are allowed, and $channelclear lets it answer everywhere again.

03

Stop commands in other channels

The step above makes the bot ignore commands elsewhere; the message still sits there. A Discord AutoMod rule deletes it.

Server Settings → AutoMod → Create your own → Custom Keywords → Block Message, and exempt your bot channel. The command list to paste is generated by the bot's own tooling, so it never goes stale.

04

Pick a pace

One command sets five dials at once, so nobody has to learn the settings table on day one.

$preset relaxed  ·  $preset normal  ·  $preset slow

$settings shows every dial afterwards, and $set <key> <value> changes one.

05

Decide what can roll

The roster carries games and Western cartoons as well as anime. A server that only wants anime can say so.

$togglegames  ·  $togglewestern

$toggles lists every switch and where it stands. They are all reversible.

06

Point people at the tutorial

$tuto walks a new player through the bot in 17 steps and pays them for finishing each one. They learn the commands by using them rather than by reading a list.
